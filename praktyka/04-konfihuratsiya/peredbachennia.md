# Передбачення: що Python прочитає з pastky.yaml

| Ключ | Моє передбачення: значення і тип | Показав perevir.py |
|---|---|---|
| svitlo | off — str | False — логічне |
| pochatok | 2026-09-28 — datetime.date | datetime.date(2026, 9, 28) — дата |
| kod_dostupu | 8 — int | 8 — ціле число |
| limit | "1e3" — str | '1e3' — рядок |
| port | 8080 — int | 8080 — ціле число |
| komentar | None — NoneType | None — порожнє |

Найбільше мене здивувала пастка svitlo: off, адже я очікував, що Python сприйме off як звичайний текст, але PyYAML перетворює його на логічне значення False. Це може спричинити помилки, якщо програма очікує рядок. Щоб уникнути такої ситуації, потрібно брати значення в лапки: svitlo: "off".
