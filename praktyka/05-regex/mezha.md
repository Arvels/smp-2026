# Межа застосування регулярних виразів

Я не став би використовувати регулярні вирази для перевірки правильності шахових ходів у грі, оскільки допустимість ходу залежить від розташування всіх фігур та правил гри. Регулярний вираз може перевірити формат запису ходу, але не визначить, чи не залишає він короля під шахом. Для такої перевірки краще застосувати програмну логіку з моделлю шахової дошки.
