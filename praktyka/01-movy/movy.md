**1. Terraform (HashiCorp Configuration Language — HCL)**
   
Terraform використовую для опису та керування хмарною інфраструктурою, зокрема ресурсами AWS. Його кінцеві користувачі — DevOps-інженери, Cloud Engineers та адміністратори інфраструктури. Terraform дозволяє швидко створювати сервери, мережі, бази даних та інші ресурси за допомогою декларативних конфігурацій замість ручного налаштування через вебінтерфейс. Його межа — керування внутрішньою логікою застосунків: Terraform не варто використовувати замість повноцінних мов програмування або систем конфігурації операційних систем.



**2. Kubernetes YAML**
   
Kubernetes YAML використовую для опису розгортання та роботи контейнеризованих застосунків у Kubernetes і OpenShift. Основні користувачі — DevOps-інженери, системні адміністратори та команди розробки. Ця предметна мова дозволяє просто визначати кількість реплік, мережеві сервіси, ресурси контейнерів і правила масштабування, які інакше довелося б налаштовувати багатьма окремими командами. Її межа — реалізація бізнес-логіки застосунків і складних алгоритмів, для яких потрібні мови програмування загального призначення.



**3. SQL (Structured Query Language)**
   
SQL використовую для роботи з реляційними базами даних, зокрема PostgreSQL та Amazon Aurora. Його кінцеві користувачі — розробники, адміністратори баз даних та аналітики. SQL дозволяє швидко знаходити, фільтрувати, об'єднувати й агрегувати великі обсяги даних за допомогою коротких декларативних запитів. Його межа — складна прикладна логіка, взаємодія із зовнішніми сервісами та керування інфраструктурою, для яких доцільніше використовувати Python, C# або інші мови програмування.
