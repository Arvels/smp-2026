# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git clone` | Клонує репозиторій з сайту на комп'ютер | Коли потрібно склонувати репозиторій до себе |
| `git status` | Відібражаю статус проекта у консолі | Коли потрібно перевірити статус проекта |
| `git diff` | Відібражаю зроблені відміності | Коли потрібно подивится які відмінности були зроблені |
| `git add` | Добавляє файл до проекта | Коли потрібно додати файл до проекта |
| `git commmit` | Створює окреме повідомлення про що буле зроблено | Коли треба створити повідомлення |
| `git push` | Зберігає зміни зроблені на комп'тері до проекта на сайті | Коли треби зберегти зроблені зміни |
| `git log` | Показую список усіх золблених комітів | Коли потрібно подивитися список зроблених комітів |
