# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git clone` | Клонує репозиторій з сайту на комп'ютер | Коли потрібно склонувати репозиторій до себе |
| `git status` | Відібражаю статус проекта у консолі | Коли потрібно перевірити статус проекта |
| `git diff` | Відібражаю зроблені відміності | Коли потрібно подивится які відмінности були зроблені |
| `git add` | Добавляє файл до проекта | Коли потрібно додати файл до проекта |
| `git commmit` | Створює окреме повідомлення про що буле зроблено | Коли треба створити повідомлення |
| `git push` | Зберігає зміни зроблені на комп'тері до проекта на сайті | Коли треби зберегти зроблені зміни |
| `git log` | Показую список усіх золблених комітів | Коли потрібно подивитися список зроблених комітів |
| `git branch` | Показує існуючі та вибрану гілкі, при дописанні назви створює окрему гілку | Коли треба створити окрему гілку |
| `git checkout -b` | Створює окрему гілку та відразу переключає на неї | Коли треба створити окрему гілку та перекоючитися до неї |
| `git merge` | Зливає гілку с основним проектом | Коли треба злити гілку з основним проектом |

## Передбачення

У якому розділі — чи розділах — git status покаже eksperyment.txt?
У розділі Changes to be committed та Changes not staged for commit.

Який рядок покаже git diff, а який — git diff --staged?
git diff показує Рядок 1, Рядок 2 двічі, та Рядок 3, а git diff --staged показує тілки Рядок 1 та Рядок 2.

Що потрапить у коміт, якщо зараз зробити коміт без add? Що покаже git status після нього?
У коміт потрапить тільки Рядок 1 та Рядок 2, та в статусі буде Changes not staged for commit.
