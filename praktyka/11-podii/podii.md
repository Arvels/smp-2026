```text
✅ 2. Enter у полі робить те саме, що кнопка «Порахувати»
✅ 3. Esc очищає поля
✅ 4. «abc», порожні поля, ділення на нуль — без жодної помилки Python
✅ 5. напис або поле повʼязані зі StringVar (textvariable)

Разом: 5 з 5 вимог ✅   (мінімум для зарахування — 4 з 5)
```

## Таблиця подій

| Подія | Що робить | Чому саме така |
| --- | --- | --- |
| `command` кнопки «Порахувати» | Викликає `porakhuvaty()`: зчитує два числа, виконує вибрану операцію й показує результат або зрозуміле повідомлення про помилку. | Натискання головної кнопки — очевидний спосіб виконати обчислення; функцію передано без дужок (`command=porakhuvaty`). |
| `<Return>` у полях `pole_a` і `pole_b` | Викликає ту саму `porakhuvaty(podiia=None)`, що й кнопка «Порахувати». | Enter дозволяє обчислити результат з клавіатури, не перемикаючись на мишу; обробник приймає необовʼязковий обʼєкт події. |
| `<Escape>` у вікні `vikno` | Викликає `ochystyty(podiia=None)`: очищає обидва поля та скидає результат до `—`. | Esc зазвичай означає скасування або очищення; прив'язка до вікна дає змогу користуватися нею з будь-якого поля. |

**Відмінність:** у моєму калькуляторі `command=porakhuvaty` передає функцію кнопці для виклику без аргументів, а `bind("<Return>", porakhuvaty)` і `bind("<Escape>", ochystyty)` пов'язують функції з клавіатурними подіями та передають їм об'єкт події.
